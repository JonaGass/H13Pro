imagebon 10.26 인치 안드로이드 오토/카플레이 모니터 부팅 로고 변경

%ec%9d%b4%ea%b2%83%ec%a0%80%ea%b2%83 android auto car play h10 pro imagebon 부팅 안드로이드 오토 카플레이

알리에서 판매 중인 imagebon사의 10.26 인치 안드로이드 오토/카플레이 모니터 H10 Pro 모델의 부팅 로고를 변경하는 방법입니다.

제품 링크: imagebon사의 10.26 인치 안드로이드 오토/카플레이 모니터 H10 Pro

 

기본으로 아래 부팅 로고가 5초 정도 표시됩니다.

위 로고를 아래처럼 변경해보았습니다.

 

변경방법

먼저 펌웨어 파일을 “Rockchip Create Upgrade Disk Tool”을 이용하여 SD에 기록합니다.

이후 SD를 기기에 넣고 전원을 키면 펌웨어 업데이트가 진행되고, 마지막에 SD를 제거하라고 나옵니다. SD를 제거하면 업데이트된 펌웨어로 기기가 시작됩니다.

각종 설정 과정을 진행하지 말고 바로 기기를 종료합니다. 설정을 진행해도 되지만 로고 변경 후 다시 설정해야 됩니다.

SD를 PC에 연결하면 아래 파일들이 표시됩니다.

이 중 logo 파일이 부팅 로고 이미지입니다. bmp 형식으로 되어 있습니다.

이제 원하는 이미지를 최대 1600 x 600이나 원하는 크기로 설정하고, 색상은 24bit로 해서 bmp 형식으로 저장합니다. 저장된 이미지를 Windows 기본 그림판에서 열어서 잘 열리는지 확인 후 파일 이름을 logo로 변경하고, SD에 덮어쓰기 하면 됩니다.

그리고,  logo 파일의 최대 크기는 4MB를 초과하지 않아야 됩니다.

 

SD를 다시 기기에 넣고 전원을 넣어주면 업데이트 과정이 진행되고 완료 후 SD를 제거하면 변경된 로고를 볼 수 있습니다.

만약 로고가 표시되지 않고 검은 화면만 나오면 지원하지 않는 이미지 형식으로 logo 파일이 만들어진 것입니다. 이때는 기본 펌웨어 파일로 다시 업데이트하면 됩니다.

 

  • 진행 과정 중 잘못되어 기기가 벽돌이 될 수도 있으니 주의하시기 바랍니다.

  • H10 Pro 외에 같은 제조사에서 만든 다른 모델에도 적용될 것 같습니다.

  • 펌웨어 업데이트 파일은 판매자에게 요청하면 받을 수 있습니다.
